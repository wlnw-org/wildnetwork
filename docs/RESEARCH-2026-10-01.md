# Wildlife Network research notes (2026-10-01)

Labels: observed = verified from docs/pages; derived = inferred; assumed = unverified.

## Vision
Universal live map of bird and animal movement and migration worldwide, correlated with weather.
Ingest from any platform or device. Give away free capture tools. Open read API.

## What exists already (competitors)
No platform fuses acoustic + camera + human + GPS + radar on one live map with weather. (derived)

| Platform | Maps | Live? | Modality | Weather | OSS |
|---|---|---|---|---|---|
| BirdWeather map | acoustic detections, global | live | acoustic | per-station only | clients only |
| Haikubox map | acoustic, own devices | live | acoustic | no | no |
| BirdCast | migration intensity, CONUS only | nightly | radar | yes (forecast) | tooling only |
| Euro Bird Portal LIVE | weekly species maps, Europe | daily | human | no | no |
| eBird Status & Trends | modelled abundance | annual | human | no | no |
| iNaturalist map | all-taxa obs | minutes | human | no | yes |
| GBIF map | 3B occurrences | weekly to annual | mixed | no | yes |
| Wildlife Insights | camera projects | batch, embargo | camera | no | no |
| Movebank | GPS tracks | some live | GPS | offline annotation | partly |
| Motus | radio telemetry | days | telemetry | no | R pkg |
| Bird Buddy / Birdfy | feeder cams, fuzzed | live | camera | no | no |

Gaps Wildlife Network can own: multi-modal fusion, live weather correlation per species, unified sensor-network coverage map, cross-source anomaly alerts (first arrivals, mass movement nights), an open redistributable API, non-bird acoustic detections.

## External sources ranked (effort vs live signal)
1. BirdWeather GraphQL `https://app.birdweather.com/graphql`: no key, global, `newDetection` subscription, bbox/species/time filters. ~7,400 stations (observed Feb 2026). License UNPUBLISHED: email support@birdweather.com before relying on it.
2. iNaturalist `https://api.inaturalist.org/v1/observations`: no key for reads, `updated_since`, 60 req/min, per-record CC license (filter cc0/cc-by for commercial). Attribution required.
3. Movebank public JSON `/movebank/service/public/json?study_id=`: no auth for public studies, GPS, some live feeds. 1 concurrent req per IP.
4. eBird API 2.0 (free key): hours latency, but terms forbid redistribution/storage (derived, terms page 403 to bots). Display on request only. Verify in browser.
5. GBIF `https://api.gbif.org/v1/occurrence/search`: global long tail, weekly to annual latency, offset cap ~200k, filter `license=`.
6. Radar: BirdCast has no API. Raw path = NOAA NEXRAD Level II on AWS (free, minutes) + vol2bird/bioRad; Europe = OPERA via aloftdata.eu.
Camera traps: batch only everywhere public (Wildlife Insights CSV, Camtrap DP on GBIF, Agouti, TRAPPER, Animl per-deployment). Live camera data must come from our own capture agent.
Partner-only / no API: Haikubox, Bird Buddy, Arbimon, Bugg, WildTrax, Motus, Euro Bird Portal, Observation.org (OAuth by request), Wikiaves.

## Weather
Open-Meteo: `archive-api.open-meteo.com/v1/archive` (ERA5 hourly from 1940, 0.25 deg; ERA5-Land 0.1 deg), `api.open-meteo.com/v1/forecast?past_days=92` fills the ~5 day ERA5 lag. Free: no key, 10k calls/day, non-commercial only, CC-BY. Self-hostable. Plan: bucket detections into 0.1 deg x 1 h cells, fetch once per cell-day, cache; self-host past ~10k/day.
Fallbacks: Copernicus CDS (bulk backfill), Meteostat, NOAA ISD, OpenWeatherMap (paid).

## Our own projects
- WDX v0.1: JSON schema, NDJSON batches, Darwin Core + Camtrap DP mapping. File format only, no transport, no producers. Becomes the canonical event format.
- birdecho: BirdWeather (REST + GraphQL), BirdNET-Go `/api/v2`, BirdNET-Pi HTML scrape adapters. Reuse as connectors. Local stations have no coords.
- wildecho-api: stateless Perch 2.0 `POST /v1/identify`. Needs a producer wrapper adding deployment/time/eventId.
- SpeciesNet-Studio: items have EXIF lat/lon + captured_at + reviewed labels; exports WI CSV. Add WDX export, deploymentId, taxonId.

## Cross-cutting problems to design for
- Taxonomy: BirdNET, Perch, SpeciesNet labels differ; normalise to GBIF backbone taxonKey.
- Confidence is not comparable across classifiers; per-classifier thresholds + review.status.
- Stable global eventId (source numeric ids are not unique globally).
- Privacy: coordinate generalisation for home stations, enforce at ingest.
- Licensing: store per-event license; exclude non-redistributable sources from the open API.

## Risks to retire first
1. BirdWeather reuse terms (email).
2. eBird terms (read in browser).
3. 24 h BirdWeather subscription test for volume/stability.
4. Open-Meteo commercial clause: self-host or pay if Wildlife Network is commercial.

## Proposed architecture
Capture: `wdx-agent` for Raspberry Pi/edge (BirdNET-Pi/Go, Frigate, MegaDetector, SpeciesNet, Animl, wildecho-api) pushing WDX NDJSON. Pullers for BirdWeather, iNat, Movebank, GBIF, NEXRAD.
Exchange: WDX protocol: `POST /v1/events`, device registry + keys, taxonomy normalisation, dedupe, privacy fuzz. Postgres + PostGIS, time-partitioned.
Observe: world map with time slider, per-species movement, weather overlay, anomaly alerts, open read API.
