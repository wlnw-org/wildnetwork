# Name and logo

The Wildlife Network code is open source under the GNU AGPL v3 (see LICENSE), and you are welcome to run, study, change and share it under that licence.

The name "Wildlife Network" and the Wildlife Network logo are not covered by the code licence. They identify the project run by Arun Rajiah at wlnw.org, so that people know which map, data releases and methods they are relying on.

## You may, without asking

- Say that your software is based on, forked from, or compatible with Wildlife Network, for example "built on Wildlife Network" or "a fork of Wildlife Network".
- Refer to Wildlife Network by name when you write about it, cite its data releases, or link to it.
- Keep the name and logo in unmodified copies of the code and its documentation.

## Please ask first

- Running a public site, app or service called Wildlife Network, or with a name or logo that could be confused with it.
- Using the logo in your own product, or in a way that suggests Wildlife Network endorses or runs your project.
- Using the name in a domain name, organisation name or product name.

If you run a fork as a public service, please give it its own name and logo, and make clear that it is independent. Its data, methods and results are its own.
